# 简介

POI插件，用于导出舰娘/装备信息至noro6制空权计算机。

## 功能特性

- 支持导出所有舰娘数据或仅导出已锁定舰娘
- 支持导出所有装备数据或仅导出已锁定装备
- 一键在POI内打开noro6制空权计算机（自动导入数据）
- 复制带数据的URL链接，可在外部浏览器使用
- 简洁美观的用户界面

## 使用说明

1. 点击"打开制空权计算机"按钮，在POI内新窗口打开noro6并自动导入数据
2. 点击"复制导出链接"按钮，获取可在外部浏览器使用的URL链接
3. 单独数据选用：可以单独导出舰娘或装备数据到剪贴板（JSON格式）
