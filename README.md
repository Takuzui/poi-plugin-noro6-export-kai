# poi-plugin-noro6-export-kai

poi舰队导出插件，支持导出舰队配置到noro6制空权模拟器。

## 功能特性

- 一键导出当前所有舰队配置（包含舰娘装备、熟练度、打孔、缎带、活动贴条）
- 自动导出陆航信息
- 支持在poi内部或外部浏览器打开noro6并自动导入舰队、舰娘、装备及活动贴条
- 复制带舰队、陆航及活动贴条数据的导出链接

## 安装

在POI浏览器中选择**设置 → 扩展程序**，输入 `poi-plugin-noro6-export-kai` 并选择安装。

## 使用说明

1. **打开制空权模拟器** - 在poi内部窗口打开noro6并导入舰队、舰娘及装备数据
2. **打开noro6** - 直接在外部浏览器打开noro6并导入舰队、舰娘、装备及活动贴条，不写入临时文件
3. **复制导出链接** - 保持原有predeck链接格式，复制舰队、陆航及活动贴条数据
4. **陆航选项** - 选择要导出的基地航空队信息
